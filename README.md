# Ma Galerie Cloudinary

Projet TP Cloud Computing - UAC
Par Kighoma Felicienne, Etudiante L3 IAGE

Une petite galerie de photos en ligne. Les photos sont stockees sur Cloudinary et affichees sur un site web simple.

## Technologies utilisees
- HTML
- CSS
- Cloudinary pour heberger les images
- GitHub Pages pour publier le site

## Comment Cloudinary est utilise
Les 3 images sont televersees dans ma bibliotheque Cloudinary.
Dans le fichier galerie.html, chaque image est affichee avec son lien Cloudinary.
Aucune image n'est stockee dans le dossier du projet, tout vient de Cloudinary.

## Comment executer le projet en local
1. Telecharger ou cloner le depot
2. Ouvrir le fichier galerie.html dans un navigateur
3. Le site s'affiche, il faut une connexion internet pour charger les images Cloudinary
